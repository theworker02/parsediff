# parsediff

Parse filesystem diff paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/parsediff/

## Install / run

```bash
git clone https://github.com/theworker02/parsediff.git
cd parsediff
node src/cli.js
node --test
```
